# Documentación del proyecto — software para restaurantes

Producto nuevo **desde 0** para el cliente de D.S.I., derivado del sistema legado `punto_c`
(xHarbour + FiveWin + ADS/DBF).

## Cómo está organizada la documentación

| Carpeta | Estado | Contenido |
|---|---|---|
| [`arquitectura/`](./arquitectura/README.md) | **Vigente (en diseño)** | Nueva arquitectura del producto: vistas, decisiones, despliegue y NFR |
| [`anterior/`](./anterior/README.md) | Histórico | Set de la fase previa: análisis del legado y planeación derivada (19 documentos) |

## Regla de uso

- `arquitectura/` es la **fuente de verdad** del diseño técnico actual.
- `anterior/` es **insumo histórico**: aporta el contexto del negocio, las reglas de negocio
  y las decisiones abiertas (D1–D10), pero no define la arquitectura vigente.
